================================================================================
PROJECT MILESTONES (ALL COMPLETED ✅)
================================================================================

✅ Milestone 1: Data Preprocessing
   - File: scripts/preprocess_data.py
   - Cleans and standardizes KCC Q&A data
   - Outputs: clean_kcc.csv, kcc_qa_pairs.json

✅ Milestone 2: Embedding & Vector Storage
   - Files: scripts/generate_embeddings.py, scripts/create_faiss_index.py
   - Generates embeddings using Sentence Transformer
   - Creates FAISS index for fast similarity search
   - Outputs: kcc_embeddings.pkl, faiss_index.bin, meta.pkl

✅ Milestone 3: Semantic Query Pipeline
   - File: utils/query_handler.py
   - Embeds user queries
   - Retrieves top-k similar entries from FAISS
   - Formats results for display and LLM

✅ Milestone 4: LLM Integration
   - File: utils/llm_client.py
   - Connects to OpenRouter API
   - Uses Llama 3.1 model (free tier)
   - Generates context-aware answers

✅ Milestone 5: Streamlit UI
   - File: app.py
   - User-friendly web interface
   - Dual-mode display (offline + online)
   - Sample queries and settings

================================================================================
TROUBLESHOOTING
================================================================================

Issue: Import errors
Fix: pip install -r requirements.txt

Issue: Setup fails
Fix: Check data/sample_raw_kcc.csv exists, re-run python setup.py

Issue: Port 8501 busy
Fix: streamlit run app.py --server.port 8502

Issue: LLM not working
Fix: Check .env file has OPENROUTER_API_KEY set

Issue: Other problems
Fix: Run python test_system.py to diagnose
